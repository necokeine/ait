# ADR：移除退役的内置 Provider

- 状态：Accepted
- 日期：2026-09-07
- 来源：NEC-196，彻底移除 Echo provider。
- 修订：NEC-174 的旧模式展示，以及 ADR-009 的快照升级范围。

## 决策

删除退役 Provider 的领域枚举值、内置注册项、固定回复执行分支和桌面特殊标签。
不保留别名或执行回退。原有离线验收改用现有 Tool / Manual 适配器，继续验证
消息历史、会话绑定、Cron 幂等性、取消和持久化恢复；真实模型流程仍使用 Codex / DeepSeek。

## 旧数据

旧快照会持久化完整内置目录，即使某个 Provider 从未被使用。
读取时只忽略无法识别且没有 Agent、Run 或凭证引用的内置目录项；下一次正常原子提交保存清理结果。
带自定义 ID、URL 或凭证的连接不属于自动清理范围。

仍引用退役 Provider 的 Agent、历史 Run，以及旧模式归档不再受支持，按原有反序列化校验拒绝读取或导入。
读取失败不修改数据库，不删除 Message，不改写历史 Run 或把原 Agent 自动绑定到其他模型。
这类工作区需在旧版本保留备份、导出受支持的 Project，再导入新工作区；无法导出的退役模式历史需保留在旧版本中查阅。

## 验证

应用层测试覆盖未引用内置项的读取与持久化清理，并验证带引用或自定义连接时拒绝读取且原始数据不变。
现有 CLI 流程继续走实际 HTTP / SQLite；桌面标签测试覆盖命名预设与 Session 私有配置。
